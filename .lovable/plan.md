# NAT Gestão

Este repositório foi reconstruído para a NAT Brownies e Brigadeiros Gourmet.

## Direção
- Não recriar funcionalidades do antigo moodboard.
- Priorizar uso mobile e linguagem simples.
- Fluxo principal: compra -> produto/receita -> precificação -> venda -> resultado.
- Identidade visual: Chocolate #35150A, Cacau #55281B, Rosé #EAAC93, Rosé claro #F2C5B5 e Creme #F8EEE9.
- Títulos em GFS Didot e interface em Lato.

## Regra de desenvolvimento
Mudanças devem preservar simplicidade, responsividade e clareza para usuários sem experiência com dashboards.
