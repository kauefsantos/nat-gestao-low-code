# Publicação do case

Este repositório é uma versão de portfólio da NAT Gestão.

Para preservar a operação real:

- receitas e quantidades exibidas no código público são dados demonstrativos e fictícios;
- dados pessoais da usuária final foram removidos ou generalizados;
- credenciais e segredos administrativos não fazem parte do repositório;
- o histórico público foi reiniciado a partir da versão higienizada do projeto;
- regras de negócio, arquitetura, migrations, testes e mecanismos de segurança permanecem representativos da implementação.

A aplicação operacional e seus dados reais permanecem separados do conteúdo apresentado como portfólio público.
